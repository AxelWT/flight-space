# 二零二六随笔

## 九月

### 一、品味

```
乔布斯谈微软（1995《书呆子的胜利》）：

"The only problem with Microsoft is they just have no taste. They have absolutely no taste. I don't mean that in a small way, I mean that in a big way."
微软唯一的问题就是没品味。不是小没品味，是大没品味。

他进一步解释：所谓没品味，不是指他们做不出好东西，而是"他们不产生原创想法，也不把任何文化带进产品里"。

关于品味从哪里来，乔布斯说：
"Good taste is about exposure, not about being born with it."
品味来自见，不来自生。

"In order to have good taste, you have to expose yourself to the best things humans have done, and then try to bring those things into what you're doing."
想有品味，就去接触人类做过的最好的东西，然后把它带进你正在做的事。

毕加索说过："Good artists copy, great artists steal." 乔布斯深以为然——
品味不是凭空创造，而是把见过的最好东西"偷"进自己的作品。
```

## 八月

### 一、失败感：反思还是内耗？

```
困境：感到失败时，一个声音要我深挖本质、找破解办法；另一个声音说够了别想、压力太大。如何平衡？

方法一 — 允许想，但有边界：设 5 分钟专门复盘，打字或手写理清思路；时间到就告诉自己「今天的思考配额用完了，明天再说」。

方法二 — 区分有用的反思与无用的反刍：任何让自己难受的思考，写出来就清晰了，情绪感受程度就下降了
- 这个问题现在有答案吗？有 → 记成行动清单，停。
- 我是在找原因，还是在骂自己？找原因 → 5 分钟复盘；骂自己 → 立刻喊停。
```

### 二、影响力：输出但不炫耀

```
我想做一个有影响力的人
【总结：输出但不炫耀，证明但更多向自己】

所以我要输出，输出对他人有帮助的有价值的内容
（你的见解，比如你对技术标准有自己的突破，都是在输出自己灵魂拥有的东西，吸引别人的认同和长期信任/尊敬）

但我不需要炫耀（例如炫耀我进了什么门槛，我有什么资源，一旦你资源丢失了，人群也就散了，身外之物没有内化进你的灵魂）

最后我不想怀才不遇，我是一个 E 人，我要输出的是自己灵魂的东西，来找寻认同。
【你脑子里的东西，你解决问题的方式，你眼睛里的东西，你这个人本身】

-----更深一层-----

无论是炫富，耍帅，还是输出认知，底层驱动力都是，我想要被看见，被认同，被重视；这是人类的社会性本能，不是缺点，甚至是创造力的燃料。

⚠️真正的问题从来不是，我想要被认同，而是我用什么换认同！
炫耀资源：希望别人因为我拥有的东西认同我
【你有，我没有，所以我高看你，但是当你没有资源的时候，谁还在乎你？】
输出认知：希望别人因为我产出的东西认同我
【你讲的做的对我有用，所以我信任你，信任会随着时间加深】

⚠️想明白这些问题，你不是在消灭欲望，而是在升级欲望

-----关联：证明----

想要证明自己本身没有错，它是人类进化的动力之一；错的是，你把证明的裁判权交给别人。
【向自己证明，完成自己的目标，成长，自己感受自己的成长，更自信；
向别人证明，别人心情不好，懒得夸你，你威胁到别人，打压你，每个人有不同的标准】

那追求影响力的路上，要不要证明？
要，你输出认知，灵魂内容，本质上还是在证明
但你证明的是我对世界的理解是有价值的，我解决问题的能力是真实的。
而且这个证明是邀请式的，不是强迫式的；
我不逼你认同我，我把东西放在这里，你觉得有用，自然会被吸引，你不吸引，也不影响我继续打磨
```

## 七月

### 一、沟通

```
不要做伤害孩子安全感的事情，教育孩子就是给够安全感 —— 段永平
同理，自己在有安全感的时候会更有创造力

正常流程：分清是谁抛出话题 > 表示关注 > 如果感兴趣则追问细节 > 互相分享 > 兴趣减弱会话自然结束
若不是该流程，可能双方存在某种较为强烈的情绪，或存在某种坏习惯

【沟通的本质】
沟通的目的有两层：信息传递 + 情感连接

【对话的正常节奏】
你抛出话题 → 对方接住（表示关注） → 追问细节 → 你回答细节 → 对方分享相似经历或观点 → 循环
以上循环表示对方对你的话题感兴趣。如果对方接住后不展开，则对话自然结束。
同理，对方抛出话题时，流程也是一样的——关键在于双向流动。

【根据兴趣决定回应方式】
- 想继续聊 → 积极推动节奏：提问 + 关联分享，让话题延伸
- 兴趣减弱但仍愿互动 → 切换到共鸣模式：简短过渡（如"我明白那种感觉…"），分享相关经历或感受
- 不想继续聊 → 温和收尾：简短总结性回应（如"原来如此""听你这么说还挺不容易的"）+ 微笑/点头，让话题自然冷却

【三种对话节奏对比】
- 正常节奏（螺旋式上升，双向流动）：A 说 → B 问/接 → A 答 → B 关联分享 → A 再问/接 → ……
- 独角戏节奏（单向输出，话题中断）：A 说 → B："哦。"（或直接转移到自己身上长篇大论）→ A 失去兴趣
- 审讯节奏（缺乏分享，像面试）：A 说 → B 不停提问 → A 不停回答 → B 继续提问 → ……

【Stop Doing List】
- 对方接过你的话题但全权引导到自己身上，且不把话题抛回来——说明他对你的话题不感兴趣，可以不聊了
- 明白自己的最初目的是分享，而非强行让对方感兴趣
- 对话中注意观察自己的情绪，再观察对方的情绪
```

### 二、经济

```
- GDP 增长从 8% 降到 5%，可能意味着近 30% 的人面临就业困难——增速的微小下降，对应的是大量个体的困境
- 思考经济学问题时，要避免非黑即白、非此即彼的是非观。取而代之的方法论是权衡利弊。非黑即白是一种危险的思维方式，因为它忽视了现实中的折中与代价
```

### 三、文化

```
有个说法：西方社会是平面社会，东方社会是等级社会
- 西方：每个人追求超越自己，激发自我潜能——冒险家冒着死亡风险突破极限，动力来自内在
- 东方：你追求的是"上等级"，本质上是追求比别人强——但当目的是比别人强时，就累了，因为人太复杂、比较永无止境

追求"人上人"的困境在于：标准是外部的、相对的、永远在变的。而追求"超越自己"的标准是内部的、绝对的、由自己定义的。前者是零和博弈，后者是正和博弈。
```

### 四、科学

```
- 科学不是立场，不是政治，不为权力妥协——它是客观事实和规律
- 遵循科学，就是要用数学的推理逻辑和数据量化，来定性定量地描述问题、描述事实、解决问题
- 科学的核心精神：可证伪性——一个理论如果无法被证伪，就不属于科学范畴
```
