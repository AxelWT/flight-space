# 幽默感

> 幽默是智力过剩的表现。 ——佚名

## 一、幽默的理论

幽默并非单纯"好笑"，它背后有几条被反复验证的机制。

### 1. 失谐理论（Incongruity Theory）

笑源于"预期"与"现实"的错位。大脑预测一个走向，结果走向另一个，这种落差产生笑。

> 例：我戒烟戒酒戒赌，因为我没钱了。

### 2. 优越理论（Superiority Theory）

笑源于"我比他好"的微妙优越感。看到别人倒霉、犯傻、出糗，我们笑，是因为"还好不是我"。

> 例：一个人踩到香蕉皮摔倒——好笑；自己踩到——不好笑。

### 3. 释放理论（Relief Theory）

笑是紧张情绪的释放阀门。许多笑话先制造紧张（禁忌、危险、尴尬），再以意外方式化解，于是"忍不住"地笑出来。

> 例：黑色幽默、地狱笑话多走这条路。

### 4. 乖讹-消解模型（SST）

现代认知心理学对失谐理论的细化：先出现"乖讹"（不对劲），听者尝试"消解"（找到另一种说得通的解释），消解成功的瞬间产生笑。

> 笑点 = 不对劲 + 可解释。二者缺一不可。

## 二、幽默的类型

| 类型 | 特点 | 代表 |
|------|------|------|
| **无厘头** | 反逻辑、反常规，纯粹荒诞 | 周星驰电影 |
| **冷笑话** | 故意用错逻辑或谐音，效果在于"冷" | 详见《冷笑话》 |
| **黑色幽默** | 把沉重话题用轻松方式讲，反差强烈 | 《第22条军规》 |
| **自嘲** | 拿自己开刀，安全且讨喜 | 脱口秀开场常用 |
| **讽刺** | 借笑批评，锋芒在内 | 鲁迅、马克·吐温 |
| **谐音梗** | 利用语言双关 | 王建国（脱口秀） |
| **Callback** | 前面埋的梗后面再提，产生"原来如此"的回响 | 脱口秀进阶技巧 |

---

## 三、好幽默的几条原则

1. **向下不向上** — 自嘲安全，嘲笑弱势者讨嫌。
2. **冒犯要精准** — 幽默可以冒犯，但要冒犯"有权有势"的方向，而非"已经不容易"的方向。
3. **真话才好笑** — 越是真切的观察，越容易引发共鸣的笑。
4. **节奏 > 内容** — 同一个笑话，不同人讲效果天差地别，差别在停顿和语气。
5. **Callback 是必杀技** — 让人想起"前面那一段"，会产生智力上的奖励感。

## 四、段子收集

> 这一节持续收集我觉得有质感的段子。好笑是基础，有回味是加分。

### 关于生活

- 我从小就立志做一个有用的人，长大后才发现——做一个没用的人，更难。
- 我的存款和我对人生的理解一样——都没多少，但都觉得自己懂了。
- 早起毁一天，晚起毁一上午，午起毁一生。

### 关于工作

- 老板说"我们是一家人"的时候，通常接下来就要你加班。
- "你在团队里很重要" = "这事除了你没人愿意干"。
- 程序员三大幻觉：这 bug 不在我代码里、这版不会出问题、我下班前能搞定。

### 关于关系

- 我和我对象的默契是——我说什么她都不信，她说什么我都道歉。
- "你最近瘦了"是朋友能给你的最高赞美，"你最近胖了"则是敌人也说不出口的话。

### 经典对白

> 钱钟书《围城》：
> "结婚仿佛金漆的鸟笼，笼子外面的鸟想住进去，笼内的鸟想飞出来；所以结而离，离而结，没有了局。"

> 马克·吐温：
> "有时候真实比小说更加荒诞，因为虚构是在一定逻辑下进行的，而现实往往毫无逻辑可言。"

> 王小波：
> "一个人活在这世界上第一要好好做人，第二不要惯坏了别人的坏脾气。"

- "曾经有一份真挚的爱情放在我面前……" ——《大话西游》
